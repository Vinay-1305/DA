# FraudShield — Online Fraud Detection

A data analysis and machine learning project focused on analyzing online financial transactions and identifying patterns associated with fraudulent activities.

---

## Overview

Financial fraud is a major challenge in digital payment systems. This project analyzes transaction data to understand fraudulent behavior, identify important transaction patterns, and prepare the data for fraud detection using machine learning techniques.

The project covers the complete data analysis workflow, including data preprocessing, exploratory data analysis, visualization, feature analysis, and predictive modeling.

---

## Objectives

- Analyze online financial transaction data.
- Identify patterns associated with fraudulent transactions.
- Clean and preprocess the raw dataset.
- Perform exploratory data analysis (EDA).
- Visualize transaction and fraud-related patterns.
- Identify important features related to fraudulent activity.
- Apply machine learning techniques for fraud classification.
- Evaluate model performance using appropriate classification metrics.

---

## Dataset

The project uses an online financial transaction dataset containing information related to transactions, account balances, transaction types, and fraud indicators.

### Dataset

`onlinefraud.csv`

### Major Data Attributes

The dataset contains transaction-related features such as:

- Transaction type
- Transaction amount
- Sender balance
- Receiver balance
- Transaction-related account information
- Fraud classification

The target variable represents whether a transaction is fraudulent.
